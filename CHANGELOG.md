# Changelog

All notable changes to the Tangram layers packages are documented here.

## 1.0.0-alpha.0

- Established the vis.gl-style workspace layout with renderer, layer, example,
  website, and development utility workspaces.
- Added the `@vis.gl/dev-tools`-based test, lint, coverage, and release command
  surface while retaining the renderer's dedicated Rollup build.
- Added package-entry smoke tests and a shared private test-utils workspace.
